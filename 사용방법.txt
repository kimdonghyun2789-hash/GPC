============================================
 GPC IP Lens 사용방법
============================================

GPC IP Lens는 아이디어별 특허 검토 관리 도구입니다.
아이디어를 입력하고 [검토 시작]을 누르면 특허 검색부터
보고서 생성까지 자동으로 진행됩니다.


1. 처음 한 번만 하는 일
--------------------------------------------
1) "1_처음설치.bat"을 더블클릭합니다.
2) 설치가 끝나면 폴더에 ".env" 파일이 생깁니다.
3) ".env" 파일을 메모장으로 열어 설정 정보를 입력하고 저장합니다.
   (설정 정보는 담당자에게 받거나 README.md를 참고하세요)


2. 프로그램 실행
--------------------------------------------
"2_프로그램실행.bat"을 더블클릭합니다.
잠시 후 브라우저가 자동으로 열립니다.
종료하려면 검은 창을 닫으면 됩니다.

[핸드폰에서 쓰고 싶을 때]
"4_핸드폰접속.bat"으로 실행하세요.
 1) 핸드폰을 컴퓨터와 같은 와이파이에 연결합니다.
 2) 화면 왼쪽 "핸드폰에서 보기"의 QR코드를
    핸드폰 카메라로 찍으면 바로 열립니다.
 3) 방화벽 허용 창이 뜨면 "허용"을 누릅니다.
핸드폰에서도 검토상태 변경, 검토의견 수정, 관심특허
추가 등 모든 기능을 그대로 쓸 수 있습니다.
(컴퓨터의 검은 창이 켜져 있는 동안에만 접속됩니다)


3. 아이디어 검토 (기본 사용 흐름)
--------------------------------------------
1) 왼쪽 메뉴에서 "아이디어 검토"를 선택합니다.
2) 기술 아이디어를 문장으로 입력합니다.
   예) PC 중공기둥에 배수 슬리브를 선매립하여 시공 중
       유입된 빗물을 외부로 배출하는 구조
3) 검색 범위를 선택합니다. (국내특허 / 해외특허 / 국내+해외)
4) 유사특허 표시 개수를 선택합니다. (10 / 20 / 30 / 50, 기본 20)
5) [검토 시작] 버튼을 누릅니다.

버튼 하나로 아래가 자동 진행됩니다.
 - Idea ID 자동 생성 (예: GPC-IP-20260612-001)
 - 아이디어 저장
 - 핵심 키워드 추출
 - 특허 검색
 - 유사특허 분석
 - 기본 통계
 - 청구항 키워드 매칭
 - 차별화 포인트 초안
 - 보고서 생성 (HTML + Excel)

결과 화면에서
 - "특허 상세보기"에서 특허별 자세한 내용을 확인하고
   "관심특허 추가"로 저장할 수 있습니다.
 - "차별화 포인트"는 직접 수정할 수 있고, 수정 내용은
   보고서에 자동 반영됩니다.
 - 화면 아래에서 보고서를 내려받을 수 있습니다.


4. 아이디어 관리
--------------------------------------------
왼쪽 메뉴 "아이디어 관리"에서
 - 지금까지 검토한 아이디어 목록을 보고
 - 검토상태를 변경하고 (아이디어 등록 / 검색 완료 / 검토 중 /
   변리사 검토 필요 / 출원 검토 / 출원 완료 / 보류)
 - 검토의견을 적고
 - 보고서를 다시 열고
 - 필요 없는 아이디어를 삭제할 수 있습니다.

[신규 공개특허 확인]을 누르면 검토일 이후 새로 공개된
특허만 골라 유사도 등급과 함께 보여줍니다.

같은 아이디어를 다시 검토하면 결과 화면 위에
"이전 검토 대비 신규 발견 N건"이 자동으로 표시됩니다.


5. 관심특허 / 보고서
--------------------------------------------
 - "관심특허": 저장한 특허를 모아 보고 검토의견을 수정합니다.
 - "보고서": Idea ID별 보고서를 미리보고 내려받습니다.


6. 동의어 사전 (검색 정확도 높이기)
--------------------------------------------
"data" 폴더의 "synonyms.csv" 파일에 같은 뜻의 용어를
등록해 두면 검색과 분석에서 같은 단어로 취급합니다.
 예) 대표어: pc / 동의어: 피씨 | 프리캐스트 | precast
Excel로 열어 행을 추가하고 저장하면 바로 적용됩니다.
영문 동의어를 등록하면 해외 검색 정확도가 올라갑니다.


7. 문제가 생겼을 때
--------------------------------------------
 - "특허 검색을 사용할 수 없습니다"가 나오면
   .env 파일의 설정 정보를 다시 확인하세요.
   화면의 "상세 오류 보기"에서 원인을 볼 수 있습니다.
 - 프로그램이 실행되지 않으면 "3_오류확인.bat"을 더블클릭해
   점검 결과를 확인하세요. (오류로그.txt에 저장됩니다)


※ 주의사항
본 도구의 결과는 기술 검토 및 선행특허 조사 지원을 위한
참고자료입니다. 실제 권리범위, 침해 여부, 신규성, 진보성
판단은 변리사 검토가 필요합니다.
